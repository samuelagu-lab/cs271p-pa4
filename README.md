# CS 271P — PA 4: Weighted Stable Garden (Z3 optimization)

My work for CS 271P (Introduction to Artificial Intelligence) at UC Irvine.

- **My submission:** `PA_4___Part_____Submitted_Problem_export/solver.py`
- The framework, test scripts, notebooks and instructions were provided by the course.

## Run the local tests

```
cd "PA_4___Part_____Submitted_Problem_export"
python3 test_local.py
```

`solver.py` at the top level is an earlier version of the solver, kept for reference; the one inside the
`PA_4___...` folder is the full version beside the test framework. The `final_*.txt` and `*_decomp*.txt`
files are logs from local test runs.

Requires Z3: `pip install -r requirements.txt` (inside the `PA_4___...` folder).
